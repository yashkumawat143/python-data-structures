Basic Level Questions tuple....



1....Create a tuple and print it.
answer : 

n1=input("Enter the elements : ");

answer :

answer :

answer :

answer :

18....Find sum of tuple elements.
answer : 

n1=input("Enter the elements : ");
answer=tuple(map(int,n1.split()));
sum=0;
for i in answer:
    sum=sum+i;
print(sum);

19....Find average of tuple elements.
answer : 

n1=input("Enter the elements : ");
answer=tuple(map(int,n1.split()));
sum=0;
count=0;
for i in answer:
    sum=sum+i;
    count+=1;
average=sum/count;
print(average);
