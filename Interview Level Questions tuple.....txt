1....Create dictionary using two tuples.
answer : 

n1=input("Enter the elements : ");
n2=input("Enter the second element : ");
answer1=tuple(n1.split());
answer2=tuple(n2.split());

d=dict(zip(answer1,answer2));
print(d);

3....Find union of two tuples.
answer : 

n1=input("Enter the first element : ");
n2=input("Enter the second element : ");
answer1=tuple(n1.split());
answer2=tuple(n2.split());
num=();

for i in answer1:
    if(i not in num):
        num+=(i,);
for j in answer2:
    if(j not in num):
        num+=(j,);
print(num);
