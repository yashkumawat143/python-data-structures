1....Find common elements between two sets A = {1,2,3,4} and B = {3,4,5,6}.
answer :

s={1,2,3,4,5};
s1={2,5,6,7,8};
print(s.intersection(s1));



2....Find all elements from both sets combined (no duplicates).
answer :

s={1,2,3,4,5};
s1={7,6,7,8,4};
print(s.union(s1));



3....Find elements in A that are not in B.
answer :

s={1,2,3,4,5,6};

5....Check if {1, 2} is a subset of {1, 2, 3, 4}.
answer :
s={1,2,3,4,5};
s1={1,2};
if(s1.issubset(s)):
    print("It is subset");
else:
    print("It is not a subset");



6....Check if {1, 2, 3} is a superset of {1, 2}.
answer :

a={1,2,3,4,5};
b={1,2};
if(a.issuperset(b)):
   print("It is superset");
else:
   print("It is not a superset");
